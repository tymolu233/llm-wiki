# Open Markdown Vault (Vendor-Agnostic)

The knowledge base vault is built purely on standard CommonMark, YAML frontmatter, and standard relative or wikilink syntax on the local filesystem. It does not depend on Obsidian APIs, Obsidian desktop runtime, or proprietary plugins.

While designed to feel first-class when viewed inside Obsidian, it can be viewed and edited in VS Code, Foam, Cursor, Typora, GitHub web, or plain terminal text editors.
